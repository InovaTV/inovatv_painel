# InovaTV Painel

Painel administrativo oficial da plataforma InovaTV.

## Objetivo

Este projeto será responsável por administrar toda a plataforma InovaTV.

Não armazenará conteúdo.

Todo o conteúdo será administrado através do Supabase.

## Componentes administrados

- Aplicativos
- Banners
- Notícias
- Tutoriais
- Downloads
- Configurações
- Atualizações
- Conteúdo da Central

## Integração

- Supabase Database
- Projeto Downloads (Vercel)
- Aplicativo InovaTV Central

## Status

Em desenvolvimento.
