# Design Studies — arquivo histórico

Este diretório guarda material de **deliberação**, não documentação
vigente. A referência normativa para qualquer implementação visual do
InovaTV Painel é sempre `DESIGN_SYSTEM.md`, na raiz do repositório —
nunca os arquivos aqui dentro.

## `identidade-visual-inovatv.html`

Registro do processo que levou à identidade visual fechada em
`DESIGN_SYSTEM.md` §5 (2026-08-07, commit `d809c54`). Conteúdo
congelado no estado em que a decisão foi tomada — não é atualizado
depois disso.

Cobre:

- As referências reais do ecossistema InovaTV/UniTV que motivaram o
  estudo (ícone do app UniTV, banner de marketing), e por que nenhuma
  das duas foi copiada diretamente para o painel.
- Os três conceitos de identidade comparados lado a lado — **Tech**
  (azul corporativo), **Streaming** (violeta) e **InovaTV** (teal,
  vencedor) — cada um com paleta e preview de UI aplicado a um recorte
  real do painel.
- A rodada de refinamento que isolou a variável matiz do teal (a
  proposta inicial, `#12897D`, lia como software clínico) até chegar
  em `#0F6D76`, a cor primária oficial.

Útil para entender **por que** A e B foram descartados, ou por que o
teal final não é o teal proposto inicialmente — não para consultar
valores de token atuais (esses vivem só em `DESIGN_SYSTEM.md`).
